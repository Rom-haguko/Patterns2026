# Описание доменных сущностей

## Простые сущности (низкого порядка)

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Единица измерения (Unit) | Базовая мера количества (г, мл, кг, шт.) | Используется в Ингредиенте |
| Деньги (Money) | Атомарная финансовая сущность (сумма + валюта) | Используется в Блюде, Контракте |
| Ингредиент (Ingredient) | Наименование сырья + количество | Ссылается на Единицу измерения; входит в Блюдо, Технологическую карту, Склад |
| Адрес / Адрес доставки (Address / Delivery Address) | Геолокационный атрибут | Используется в Ресторане, Заказе |
| Сотрудник (Employee) | Персонал (имя, должность) | Используется в Контракте, Графике работы |
| Контрагент (Counterparty) | Поставщик / юридическое лицо | Используется в Контракте |
| Группа (Group) | Иерархическая сущность (группа единиц измерения / контрагентов) | Ссылается сама на себя (родитель-потомок) |

## Комплексные сущности (высокого порядка)

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Блюдо / Номенклатура блюд (Dish / Dish Nomenclature) | Список ингредиентов, их количество, стоимость | Включает Ингредиенты, Деньги |
| Технологическая карта (Technological Card) | Спецификация блюда: раскладка, граммовка, порядок операций | Ссылается на Блюдо и Ингредиенты |
| Склад (Storage) | Хранилище остатков ингредиентов/полуфабрикатов | Содержит Ингредиенты; принадлежит Ресторану |
| Ресторан (Company) | Филиал сети | Включает Адрес, Склад, список Блюд |
| Контракт (Contract) | Документ, связывающий контрагента и сотрудника | Ссылается на Контрагента, Сотрудника, Деньги |
| График работы (Work Schedule) | Расписание смен | Включает Сотрудника и временные интервалы |
| Заказ (Order) | Клиент → проверка склада → кухня → комплектация → доставка | Ссылается на Склад, Блюдо, Адрес доставки |
